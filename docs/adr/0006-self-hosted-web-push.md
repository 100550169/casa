# ADR-0006 · Standard Web Push with VAPID, no third-party provider

**Status:** accepted

## Context

Usage showed forgotten chores: the app only helped when someone opened it. Phone notifications
were needed, on iOS and Android, at no cost and without handing minors' data to third parties.

## Decision

- **Web Push** (RFC 8030) with the `web-push` library and **VAPID** keys generated by the server
  and persisted in `casa_meta` when they are not configured.
- What to notify is decided by pure functions (`services/avisos.js`): events derived from
  comparing the state before and after, never addressed to their author and grouped by recipient.
- Only subscriptions from known push services are accepted (prevents SSRF). Expired ones
  (`404`/`410`) are removed automatically.
- Delivery happens after responding to the client.

## Alternatives

- **Firebase Cloud Messaging / OneSignal**: external dependencies and accounts; data leaves the
  household.
- **Email or messaging apps**: require minors' email addresses or phone numbers.

## Consequences

- ✅ No cost and no third party with access to the household's content.
- ⚠️ On iOS it only works with the PWA installed on the home screen (iOS 16.4+).
