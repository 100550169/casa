# User guide

A guide for the people who use the app every day. No technical knowledge required.

> The interface is in Spanish. Button and screen names are quoted as they appear in the app,
> followed by their English meaning.

## 1. First access

1. Open the app's address in the browser (or the link you were sent).
2. If the household has a code and this is the first visit from that device, **"Esta casa es
   privada"** (*this household is private*) appears: type the code.
3. Pick your profile under **"¿Quién eres?"** (*who are you?*):
   - one of the **three child profiles** → the mobile app, with your chores and your allowance;
   - **the parents' dashboard** → administration, designed for a computer.

There is no sign-up, email or password. The device remembers the profile; to change it, use the
**Cambiar** (*switch*) button in the top bar.

> A slow first load is expected: the free server sleeps after 15 minutes without traffic and
> takes up to about a minute to wake up.

## 2. Installing the app on a phone

It then behaves like any other app, with an icon and full screen. On iPhone it is **required**
to receive notifications.

**Android (Chrome):** menu **⋮** → **Install app**.

**iPhone (Safari, not Chrome):** **Share** → **Add to Home Screen** → **Add**. From then on, open
the app **from its icon**.

## 3. Enabling notifications

1. Open the app from its icon.
2. Children: card **"Que no se te olvide nada"** → **Activar avisos** (*enable notifications*).
   Any profile: **Cambiar** → **Avisos en este móvil** (*notifications on this phone*).
3. Accept the permission prompt. A test notification will arrive.

What you get: parents are notified when a child submits a chore or requests a reward; each child
when a chore is approved or sent back, or when someone asks for one of their chores in the
marketplace; and every afternoon, between 17:00 and 21:30, a reminder of what is pending today.

On iPhone this requires iOS 16.4 or later.

## 4. Preparing the month (parents)

From the parents' dashboard:

1. **Tareas fijas** (*fixed chores*): mark each one as daily or weekly. They are the same for
   every child.
2. **Adicionales** (*extra chores*): catalog of chores with points that earn extra money.
3. **Economía** (*economy*): fixed allowance, point value and each child's availability (normal,
   reduced, minimal).
4. **Premios** (*rewards*): what can be redeemed, with cost and quantity.
5. **Resumen → Generar mes** (*overview → generate month*): assigns the extra chores according to
   availability.
6. **Calendario** (*calendar*):
   1. under **Horarios de cada hijo** (*each child's schedule*), add the fixed weekly commitments
      (school, activities);
   2. press **Organizar semana** (*organize week*): it places pending chores in free slots and
      reports what does not fit;
   3. tap a chore to move it. Busy time is shown hatched; a conflict, in red.

The calendar repeats every week until it is changed. Each child sees **"Hoy te toca"** (*today
you have*) on their home screen and the full week in the **Semana** (*week*) tab.

## 5. Day to day

| Who | What they do |
|---|---|
| Children | Tick their daily chores, submit weekly and extra chores, request rewards, use the marketplace |
| Parents | **Validar** (*approve or send back*), **Premios** (*grant or deny rewards*), **Los hijos** (*household view and per-child detail with history*) |

The red badge on each tab shows how many items are waiting. Everything syncs between devices on
its own within a few seconds.

## 6. Troubleshooting

| Problem | Solution |
|---|---|
| It takes long to open | The server was asleep; wait a minute and reload |
| It opens with someone else's profile | **Cambiar** → pick yours |
| No icon appears on iPhone | Use Safari; if it already existed, delete it and add it again |
| It asks for a code I don't know | Parents can see it under **Economía → Acceso a la casa** (*household access*) |
| Notifications don't arrive | Open the app from its icon; check Settings → Notifications; **Avisos en este móvil → Probar** (*test*) |
| I deleted or reset something by mistake | **Economía → Copias de seguridad → Volver a esta** (*backups → go back to this one*); it can be undone too |
| I want to start from scratch | **Economía → Reiniciar datos de ejemplo** (*reset sample data*); a backup is saved first |
| I want a copy on my computer | **Economía → Copias de seguridad → Descargar copia** (*download backup*) |

The app never moves real money: it only calculates what each child has earned.
